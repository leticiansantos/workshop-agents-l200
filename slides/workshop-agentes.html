Contexto

Por que agentes?

Um LLM sozinho responde texto. Um agente raciocina, usa ferramentas, consulta dados e age — com governança.

Raciocina

Decide os passos para resolver uma tarefa.

Usa ferramentas

SQL, funções, busca, APIs.

Consulta dados

Governados pelo Unity Catalog.

É avaliável

Qualidade medida e monitorada.

Plataforma

Agentes no Databricks — o mapa

Agent Bricks

Genie, Knowledge Assistant e Multi-Agent Supervisor — no-code / low-code.

Mosaic AI Agent Framework

Agentes com código (ResponsesAgent), tools, deploy em Model Serving.

Foundation Model APIs

LLMs prontos (Llama, Claude, GTE) servidos pelo Databricks.

Vector Search

RAG gerenciado com embeddings automáticos.

Unity Catalog

Governança: dados, funções, modelos, lineage.

MLflow 3

Tracing, evaluation, monitors de produção.

Nosso caso

Domínio: operadora de saúde

Tudo que construirmos gira em torno de dados sintéticos de uma operadora de plano de saúde.

beneficiarios planos hospitais procedimentos sinistros

+ documentos: manual de cobertura, regras de carência, política de reembolso, rol de procedimentos, FAQ.

Bloco 2 · notebook 02

Genie Space — linguagem natural → SQL

Perguntas de negócio respondidas em SQL, sem escrever código.

  • "Qual a taxa de negativa de sinistros por plano?"
  • "Quais motivos de negativa são mais comuns?"
  • "Qual hospital tem maior valor aprovado?"

Boas práticas: comentários de tabela, exemplos de SQL, instruções de negócio. Consumível também via Conversation API.

Bloco 3 · notebook 03

Knowledge Assistant — RAG sobre documentos

Q&A sobre manuais de cobertura, carência e reembolso — com citação das fontes.

  • Ingestão, chunking, embeddings e indexação automáticos.
  • "Qual a carência para ressonância?" · "Posso usar hospital fora da rede?"
  • Exposto como serving endpoint — plugável em apps e no supervisor.

Bloco 7 · notebook 06

Avaliação e governança

  • Tracing — cada passo do agente (LLM, tools, latência).
  • Datasets + scorers — Correctness, Safety, RelevanceToQuery, diretrizes de negócio.
  • mlflow.genai.evaluate — compara versões lado a lado.
  • Monitors — qualidade contínua sobre o tráfego de produção.
  • Unity Catalog — lineage, permissões, auditoria fim-a-fim.
Bloco 8 · notebook 07

Capstone — agente de atendimento

Junte tudo: explique por que um sinistro foi negado, cite a carência correta e proponha o próximo passo.

  • Reaproveite o agente com código e suas tools.
  • Adicione uma nova ferramenta (simulação de reembolso).
  • Melhore o prompt e re-avalie — mostre a melhora.
